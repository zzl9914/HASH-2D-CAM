# 检测器分类法：取舍、假阳性与假阴性

## 1. 为什么要「平移不变的规范化」

朴素的周期检测是拿两代的整盘字节比对。这只能发现**原地**周期，
任何会移动的结构（滑翔机、飞船、行波）都会被判成混沌。

本 skill 改成：每代先求非零格的包围盒，把内容以包围盒左上角为原点重排成稠密副本
（`detect.normalize`）。于是：

- 副本相同、原点也相同 → 原地周期；
- 副本相同、原点不同 → 整块结构平移了 `Δ原点`。

这使得周期与位移同时被解出来，而且位移是**精确整数格**，不是估计值。

## 2. 为什么最终判定必须逐字节比对

`signature()` 是 FNV-1a 哈希，只用作 `Map` 的查找键。
命中之后一律走 `sameCrop()` 逐元素比较，相等才承认。
哈希碰撞因此只会带来无谓的比较，不会产生假结果。

同理，`Detector` 只保留最近 `periodMax` 帧的签名，`Map` 的规模是有界的。

## 3. 两道守卫

### 环绕守卫

在环面边界下，一个匀速前进的结构绕行一周后会「回到」与原位置相差整数倍
棋盘尺寸的地方，被误读成位移巨大的飞船。判据：
`|dx| > cols/2` 或 `|dy| > rows/2` 的命中直接丢弃。

这也是默认边界取 `open` 的原因之一：开放边界下根本没有环绕。

### 退化守卫（行波 vs 飞船）

一块**自身就有平移对称**的图样（例如竖直条纹、周期性纹理），
在整盘平移时也会满足「副本相同、原点移动」。但这不是飞船，是行波。

判据 `detect.degenerateShift(crop, dx, dy)`：把位移在包围盒内取模，
若取模后**非零**且裁剪块在该位移下不变，则判为退化。

取模后为 `(0,0)` 时**不判退化**，因为这时无法区分两种情况：
位移恰是包围盒尺寸的整数倍，可能真的是有限图样在下一拍于旁边重生
（这正是「飞过去一格」的常见形态），也可能是自平铺。宁可放过，不可误杀。

## 4. 已知的假阴性

| 情形 | 结果 | 原因 |
| --- | --- | --- |
| 盘面上同时有飞出的飞船和不动的碎片 | 落到 `chaotic` 或 `still` | 整盘签名不再重复；规范化只对「整块一起平移」有效 |
| 周期 > `--period` | 落到 `chaotic` | 判定窗口不够 |
| 结构在 `--max-gen` 内还在暂态 | 落到 `chaotic` / `expanding` | 反射器、长寿命暂态都属于这一类 |
| 结构在观察窗口末端才接触边界并被打乱 | 可能是 `chaotic` | 边界污染 |

第一条是最主要的限制。要缓解：`droplet` 模式、低密度、大网格，
或 `--from-pattern` 直接投放已知结构。**不要**把「没找到飞船」当成「该规则没有飞船」。

## 5. 秩序指标的三项都只是代理量

| 指标 | 定义 | 已知偏差 |
| --- | --- | --- |
| `compressibility` | `1 − |deflate(快照)| / |快照|` | 稀疏图样天然接近 1；空盘是 1.0（但空盘已被 `died` 拦下） |
| `blockOrder` | `1 − H(4×4 块模式分布)/16` | 把 4×4 块当独立样本，忽略块间相关；棋盘格会得到 1.0 却毫无结构 |
| `lag1Order` | 水平相邻格状态相同的比例 | 只看一个方向，竖条纹与横条纹得分相同 |

三者算术平均得到 `order ∈ [0,1]`。它**不是熵率**，不满足任何信息论意义上的单调性，
只用于在同一批结果之间排序。

特别地：`order` 高 ≠ 结构复杂。三格闪烁器 `order ≈ 0.995`，
而一个 30 格的大振荡子可能只有 0.9。这正是要引入体量项的原因。

## 6. 评分为什么需要体量项（实测踩出来的）

最初的形式是 `得分 = 类型权重 × (0.4 + 0.6 × 秩序)`。
在生命游戏上跑 `-m droplet`，排名前五**全部**是周期 2 的三格闪烁器，
得分 0.897 挤在一起，而滑翔机排在后面。

原因是三格闪烁器的裁剪块只有 3 字节、压缩率 0.99，秩序项接近满分。
加入体量项 `min(1, 存活数/40)` 之后，闪烁器得 0.566，
12 格的周期 3 振荡子得 0.647，滑翔机（5 格，类型权重 1.0）得 0.62。
密度与内容量重新参与了排序。

## 7. 端到端验证

判定管线用一条独立复现做了核验，值得保留为回归用例：

**规则** `B2/S34/C2/N123457`（火雨），**网格** 64×64，**边界** open，
**试验** droplet，密度 0.5，液滴 8，`salt = 599832925`。

报告给出：初始存活 28、判定于第 21 代、类型平移结构、周期 4、位移 (0,4)、吸引子存活 12。

独立重算（不调用 `Detector`，只调 `normalize` 手工比对）得到：

```text
t=17  bbox ox=28 oy=42 w=9 h=11 pop=12
t=21  bbox ox=28 oy=46 w=9 h=11 pop=12
crop(17) === crop(21): true        ← 支持 period=4, displacement=(0,4)
crop(18) === crop(22): true        ← 周期一致性
crop(20) === crop(24): true
crop(16) === crop(20): false       ← 关键：没有把更早的暂态误当成周期
```

最后一行尤其重要：它证明检测器报告的是**首次**进入刚性平移的时刻（t=17），
而不是把暂态也算进去。初始存活 28 与 t=21 存活 12 都与报告逐字相符。

复现时注意：邻域掩码必须用 `CA.maskFromNeighborhoodText('123457')`（得 95）。
