## 评分口径

`得分 = 类型权重 × (0.30 + 0.30 × 秩序 + 0.40 × 体量) × 周期项`

| 项 | 取值 |
| --- | --- |
| 类型权重 | 平移结构 1.0，振荡子 0.9，静物 0.5，扩张 0.45，混沌 0.2，消亡 0.1 |
| 秩序 | 压缩率、4×4 块序、水平邻接一致三项的算术平均 |
| 体量 | `min(1, 吸引子存活数 / 40)` |
| 周期项 | 振荡子取 `min(1.15, 0.8 + 0.06 × 周期)`，其余为 1 |

体量项是必要的：三格闪烁器的秩序接近满分（压缩率 0.99），不加体量会霸榜，把有内容的发现挤下去。

## 判读须知

- 类型是**有限预算内的观察结果**，不是证明。`--max-gen` 之内没命中周期就归为混沌或扩张，加长观察可能改判。
- 秩序三项都是启发式代理：压缩率对稀疏图样天然偏高，块序把 4×4 块当作独立样本，邻接一致只看水平相邻。它们合起来用于排序，不是熵率。
- 默认边界 `open`（界外读作 0），避免环绕造成的假周期。要复现界面默认的环面，传 `--boundary cycle`，此时位移超过半个棋盘的命中会被丢弃，以防把绕行误判成滑行。
- `field` 模式填满整个网格，适合看规则整体的收敛倾向；`droplet` 模式只在中心放一小块，适合找孤立的静物、振荡子和飞船。
- **平移结构只有在整盘一起平移时才会被识别**。如果盘面上同时有飞出去的飞船和不动的碎片，整盘签名不再重复，该次试验会落到混沌或静物。要找飞船，用小液滴、低密度、大网格，或者用 `--from-pattern` 把已知飞船丢进去。
- 位移列带 `ᵂ` 的命中，是包围盒在位移下的自洽性检验判定为「图样自身就有这个平移对称」的，多半是行波而不是飞船，得分已乘 0.55。
- 体量列带 `ᵇ` 的命中，吸引子至少占满半个棋盘。它通常不是「找到了一块结构」，而是**整盘作为一块在振荡或平移**。得分已乘 0.70。
- 判定接触边界（`接触边界 = 是`）的命中，其形态受边界条件影响，不能直接当作规则的内禀性质。
